# 1 · ติดตั้ง Claude Code บนคอมของเรา

ใช้ Claude Code ผ่าน **แอป Claude** (ฝั่ง **Code**) ไม่ต้องใช้หน้าจอดำ ไม่ต้องลงโปรแกรมอื่นเพิ่ม
ทำจบ 6 ขั้นนี้ = พร้อมใช้

## ต้องมีก่อน

- คอม **Mac** macOS 13 ขึ้นไป หรือ **Windows** 10 (เวอร์ชัน 1809) ขึ้นไป · RAM 4 GB ขึ้นไป
- บัญชี Claude แพ็กเกจ **Pro** ขึ้นไป (Pro · Max · Team · Enterprise) แพ็กเกจฟรีใช้ Claude Code ไม่ได้
- อินเทอร์เน็ต

## 6 ขั้น

### 1. ดาวน์โหลดแอป Claude

เข้า **[claude.com/download](https://claude.com/download)**

- **Mac** เปิดไฟล์ที่โหลดมา แล้วย้าย Claude เข้าโฟลเดอร์ Applications (ไฟล์เดียวใช้ได้ทั้งชิป Intel และ Apple)
- **Windows** เปิดไฟล์ติดตั้ง แล้วกดตามขั้นตอน
  (คอม Windows รุ่นชิป ARM ใช้ [ตัวติดตั้ง ARM64](https://claude.ai/api/desktop/win32/arm64/setup/latest/redirect))
- **Windows ควรลง [Git for Windows](https://git-scm.com/downloads/win) ด้วย** ไม่ลงก็ใช้ได้
  แต่ Claude จะใช้คำสั่งได้ครบกว่าเมื่อมี

### 2. เปิดแอป แล้ว Sign in

Mac เปิดจาก Applications · Windows เปิดจาก Start menu แล้ว Sign in ด้วยบัญชี Claude ของเรา

### 3. ด้านบนของแอป กด **Code** ฝั่งขวา

แอปมีสองฝั่ง

| ฝั่ง | ทำอะไร |
|---|---|
| ซ้าย · แชท (รวม Cowork แล้ว) | คุยทั่วไป และให้ Claude ลงมือทำงานให้ ไม่ได้ทำงานในโฟลเดอร์ของเรา |
| ขวา · **Code** | ทำงานกับไฟล์ในคอมเราได้ตรง ๆ **คลาสนี้ใช้ฝั่งนี้** |

### 4. เลือก **Local** แล้วกด **Select folder**

**Local** = ทำงานบนคอมเรา ด้วยไฟล์ของเรา แล้วเลือกโฟลเดอร์ที่จะทำงาน

ครั้งแรก สร้างโฟลเดอร์ว่างไว้หนึ่งอัน เช่น `claude-brain` (ใน Documents ก็ได้) แล้วเลือกโฟลเดอร์นั้น
Claude จะเห็นและแก้ไฟล์ได้เฉพาะในโฟลเดอร์ที่เราเลือก

### 5. ดูปุ่มข้างปุ่มส่ง: model และโหมด

- **Model** เปลี่ยนได้ตลอด จากปุ่มเลือกข้างปุ่มส่ง
- **โหมด** บอกว่า Claude ทำได้เองแค่ไหน ก่อนต้องถามเรา

| โหมด | Claude ทำอะไรได้เอง |
|---|---|
| **Manual** | ถามเราก่อนแก้ไฟล์หรือรันคำสั่ง **ทุกครั้ง** มีปุ่ม Accept / Reject ให้กด |
| **Accept edits** | แก้ไฟล์ได้เลย แล้วขึ้นตัวเลขอย่าง `+12 -1` ให้เรากดดูทีหลังว่าแก้อะไร |
| **Plan** | เสนอวิธีทำก่อน ยังไม่แก้ไฟล์ใด ๆ |
| **Auto** | มีตัวกรองคอยกันงานเสี่ยงให้ แล้วทำต่อโดยไม่ถาม |

### 6. ลองสั่งงานแรก

พิมพ์ในช่องพิมพ์แล้วกด Enter

> ในโฟลเดอร์นี้มีไฟล์อะไรบ้าง

Claude ตอบกลับมา = ติดตั้งเสร็จ พร้อมใช้ ส่วนจำ (Brain) เราติดตั้งด้วยกันในคลาส ([คู่มือข้อ 2](02-brain-setup.md) ไว้ดูทีหลัง)

## ใช้งานคล่องขึ้น

- **หยุดกลางทาง** กดปุ่มหยุด หรือพิมพ์บอกทางใหม่แล้ว Enter ได้เลย ไม่ต้องรอให้เสร็จ
- **ชี้ไฟล์** พิมพ์ `@ชื่อไฟล์` ในช่องพิมพ์ หรือลากไฟล์ รูป PDF มาวาง
- **คำสั่งที่เก็บไว้ (skill)** พิมพ์ `/` หรือกด **+** แล้ว **Slash commands** เพื่อดูรายการ

## ติดตรงไหน

| อาการ | ทำอย่างนี้ |
|---|---|
| กด Code แล้วขึ้นให้อัปเกรด | บัญชียังไม่ใช่ Pro ต้องสมัครแพ็กเกจ Pro ขึ้นไปก่อน |
| กด Code แล้วขึ้นให้ Sign in ออนไลน์ | ทำให้เสร็จในเบราว์เซอร์ แล้วปิดแอปแล้วเปิดใหม่ |
| Windows สั่งแล้วคำสั่งไม่ทำงาน | ลง Git for Windows แล้วเปิดแอปใหม่ |

## ข้อมูลของเรา

ลิงก์ Artifact บนแพ็กเกจ Pro เป็น **ลิงก์สาธารณะ** ใครได้ลิงก์ก็เปิดดูได้
ก่อนส่งต่อ ตัดชื่อจริง เบอร์โทร และข้อมูลลูกค้าจริงออกเสมอ
