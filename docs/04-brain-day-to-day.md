# 4 · ใช้ส่วนจำทุกวัน: จดเพิ่ม แก้ และเรียกใช้ให้ถูกงาน

ติดตั้งส่วนจำแล้ว ([ข้อ 2](02-brain-setup.md)) หน้านี้ไว้เปิดดูตอนใช้งานจริง
เรียงตาม **"ตอนนี้อยากทำอะไร"** แต่ละข้อมีประโยคที่พิมพ์ตามได้เลย

## ส่วนจำมีสองแบบ

| | ใครเขียน | อยู่ที่ไหน | Claude อ่านตอนไหน |
|---|---|---|---|
| **ไฟล์ในโฟลเดอร์งาน** `CLAUDE.md` · `core/` · `decision-log.md` | เรา หรือสั่งให้ Claude เขียน | ในโฟลเดอร์งานของเรา | `CLAUDE.md` อ่านทุกครั้งที่เปิด session ใหม่ ไฟล์อื่นอ่านเมื่อต้องใช้ |
| **โน้ตที่ Claude จดเอง** (auto memory) | Claude จดจากที่เราบอกหรือแก้ให้ | ในเครื่องเรา แยกตามโปรเจกต์ | ต้นไฟล์สรุปโน้ต อ่านทุกครั้งที่เปิด session ใหม่ |

แบบแรกส่งต่อให้เพื่อนร่วมทีมได้ เพราะอยู่ในโฟลเดอร์ แบบที่สองอยู่ในเครื่องเราเครื่องเดียว

---

## 1 · เปิดให้ถูกโฟลเดอร์ก่อนเริ่มงาน

หนึ่งงาน หนึ่งโฟลเดอร์ แต่ละโฟลเดอร์มี `CLAUDE.md` ของตัวเอง และโน้ตที่ Claude จดเองก็แยกตามโปรเจกต์
เปิดผิดโฟลเดอร์ = Claude อ่านส่วนจำของอีกงาน

- เริ่มงาน: **+ New session** ในแถบซ้าย (หรือ `Cmd+N` บน Mac · `Ctrl+N` บน Windows) แล้วเลือกโฟลเดอร์งานนั้น
- ไม่แน่ใจว่าอ่านส่วนจำถูกไหม ถาม: **ตอนนี้อ่านกติกาจาก CLAUDE.md ของโฟลเดอร์ไหน**
- ดูเองได้: พิมพ์ `/memory` จะเห็นรายการไฟล์ส่วนจำทั้งหมดที่ใช้อยู่
- แถบซ้ายจัดกลุ่ม session ตามโปรเจกต์ได้ กดปุ่มด้านบนแถบซ้าย

**เรื่องที่อยากให้ Claude รู้ทุกงาน** (เช่น "ตอบภาษาไทยเสมอ") ไม่ต้องใส่ซ้ำทุกโฟลเดอร์
สั่งว่า **ช่วยเพิ่มใน CLAUDE.md ของผู้ใช้ (ที่ใช้กับทุกโปรเจกต์) ว่า …**

## 2 · จดเพิ่ม: จดตอนไหนดี

จดทันทีที่เกิดเรื่องพวกนี้ ช้าไปวันเดียวก็ลืมว่าเพราะอะไร

| เกิดอะไรขึ้น | พิมพ์ว่า |
|---|---|
| ประชุมเพิ่งตัดสินอะไรไป | **ประชุมเมื่อกี้ตัดสินว่า … เพราะ … ช่วยเพิ่มใน decision-log.md** |
| Claude ทำพลาดแบบเดิมเป็นครั้งที่สอง | **ช่วยเพิ่มกติกาใน CLAUDE.md: ทุกครั้งที่ … ให้ …** |
| มีคนใหม่ในทีม หรือลูกค้าใหม่ | **ช่วยเพิ่ม … ใน core/team.md: ชื่อเล่น … ดูแลเรื่อง …** |
| ทำงานหนึ่งจนได้ผลที่ชอบ อยากใช้ซ้ำ | **ช่วยเก็บวิธีที่เราเพิ่งทำเป็น skill ชื่อ …** |

**ระวัง:** ถ้าพิมพ์แค่ **"จำไว้ว่า …"** Claude จะจดลงโน้ตของตัวเอง (อยู่ในเครื่องเรา)
เพื่อนร่วมทีมที่เปิดโฟลเดอร์เดียวกันจะไม่เห็น ถ้าอยากให้ทั้งทีมใช้ บอกชัด ๆ ว่า **เพิ่มใน CLAUDE.md**

## 3 · แก้: ให้สั้นและไม่ขัดกันเอง

- **`CLAUDE.md` ยิ่งยาว Claude ยิ่งทำตามน้อยลง** คู่มือทางการแนะนำไม่เกิน 200 บรรทัด
  เรื่องยาว ๆ ย้ายไปไว้ใน `core/` แล้วให้ `CLAUDE.md` บอกแค่ว่าเรื่องนั้นอยู่ไฟล์ไหน
- **กติกาสองข้อที่ขัดกัน Claude อาจเลือกข้อไหนก็ได้** เดือนละครั้งสั่งว่า
  **อ่าน CLAUDE.md กับ decision-log.md แล้วบอกหน่อยว่าข้อไหนเก่า ซ้ำ หรือขัดกัน**
- **แก้ `CLAUDE.md` แล้ว เปิด session ใหม่** Claude อ่านไฟล์นี้ตอนเริ่ม session
  ส่วน skill ที่เพิ่มหรือแก้ทีหลัง ใช้ได้เลยใน session เดิม
  (ยกเว้นโฟลเดอร์ `.claude/skills/` ยังไม่เคยมีตอนเปิด session ครั้งแรกหลังติดตั้ง ต้องเปิด session ใหม่)
- **ดูหรือลบโน้ตที่ Claude จดเอง:** พิมพ์ `/memory` แล้วเลือกโฟลเดอร์โน้ต เป็นไฟล์ข้อความธรรมดา แก้หรือลบได้
  หรือสั่งว่า **ลืมเรื่อง … ไปได้เลย ช่วยลบออกจากโน้ต**

## 4 · เรียกใช้: ให้ Claude หยิบเรื่องที่ถูกมาตอบ

- **ชี้ไฟล์ให้ชัด** พิมพ์ `@` ตามด้วยชื่อไฟล์ เช่น
  **@decision-log.md เราเคยตัดสินเรื่องราคาไว้ยังไง**
- **ขอที่มาทุกครั้งที่ต้องใช้ตัดสินใจ** **ตอบจากส่วนจำ แล้วบอกด้วยว่าอ่านจากไฟล์ไหน**
  ถ้า Claude บอกว่าไม่เจอ แปลว่ายังไม่เคยจด จดเพิ่มตามข้อ 2
- **skill เรียกได้สองทาง** พิมพ์ `/ชื่อ skill` ตรง ๆ หรือเล่างานให้ตรงกับที่ skill เขียนไว้ Claude จะหยิบมาใช้เอง
- **งานใหม่ เปิด session ใหม่** session เก่าที่คุยมายาวจะมีเรื่องเก่าปนอยู่ ตอบช้าลงและใช้โควตามากขึ้น
  - `/clear` ล้างบทสนทนา เริ่มใหม่ในโฟลเดอร์เดิม (ส่วนจำยังอยู่ครบ เพราะอยู่ในไฟล์)
  - `/compact` ย่อบทสนทนาที่ยาว แล้วคุยต่อเรื่องเดิม
- **กลับไปทำงานเดิมต่อ** เลือก session นั้นในแถบซ้าย (สลับเร็ว ๆ ด้วย `Ctrl+Tab`)

## 5 · สัญญาณว่าส่วนจำเริ่มเพี้ยน

| อาการ | ทำอย่างนี้ |
|---|---|
| Claude ไม่ทำตามกติกาที่เขียนไว้ | พิมพ์ `/context` ดูหัวข้อ Memory files ว่ามี `CLAUDE.md` ไหม ถ้าไม่มี แปลว่าเปิดผิดโฟลเดอร์ ถ้ามี ลองดูว่ายาวไปหรือขัดกันเอง (ข้อ 3) |
| ตอบเรื่องของอีกงานปนมา | เปิด session ใหม่ในโฟลเดอร์ที่ถูก (ข้อ 1) |
| จำเรื่องที่ไม่อยากให้จำ | `/memory` แล้วลบโน้ตนั้น (ข้อ 3) |
| ตอบไม่ตรงกับที่ตัดสินไว้ล่าสุด | ดู `decision-log.md` ว่าจดเรื่องล่าสุดไว้บนสุดหรือยัง |

## ข้อมูลของเรา

ส่วนจำเป็นไฟล์ข้อความธรรมดา ใครได้โฟลเดอร์ก็อ่านได้
ไม่ใส่รหัสผ่าน เลขบัตร หรือข้อมูลส่วนตัวของลูกค้าจริงลงในส่วนจำ
