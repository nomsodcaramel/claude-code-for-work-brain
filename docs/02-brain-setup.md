# 2 · ติดตั้งส่วนจำ (Brain) ใน Claude Code

**ส่วนจำ** คือโฟลเดอร์ที่ Claude อ่านเองทุกครั้งที่เปิด ข้างในมีกติกาการทำงาน ทีมของเรา
คนที่เราทำงานให้ และเรื่องที่ตัดสินไปแล้ว Claude จึงไม่ต้องให้เราเล่าใหม่ทุกครั้ง

ทำ [1 · ติดตั้ง Claude Code](01-setup-claude-code.md) ให้จบก่อน

## ติดตั้ง (ให้ Claude ทำให้)

1. ในฝั่ง **Code** เลือก **Local** แล้ว **Select folder** เป็นโฟลเดอร์ว่าง เช่น `claude-brain`
2. วางลิงก์นี้ในช่องพิมพ์ แล้วพิมพ์ต่อว่า **ช่วยติดตั้งสมองนี้ให้หน่อย**

   ```
   https://github.com/nomsodcaramel/claude-code-for-work-brain
   ```
3. ถ้า Claude ขออนุญาตโหลดไฟล์หรือรันคำสั่ง อ่านก่อนว่าจะทำอะไร แล้วกดอนุญาต
4. เสร็จแล้ว **เปิด session ใหม่ในโฟลเดอร์เดิม** (Claude จะเห็น skill ครบหลังเปิดใหม่)
5. ลองถาม **งานนี้มีใครบ้าง ตัดสินใจอะไรไปแล้ว**
   Claude ตอบจากไฟล์ในโฟลเดอร์ และบอกว่าอ่านมาจากไฟล์ไหน
6. ลองพิมพ์ **/meeting-slide** ใช้ transcript ประชุมตัวอย่างที่ให้ไว้ ได้สไลด์สรุปประชุมเป็นลิงก์

## ติดตั้งเอง (ถ้าอยากทำมือ)

1. โหลด ZIP: <https://github.com/nomsodcaramel/claude-code-for-work-brain/archive/refs/heads/main.zip>
2. แตกไฟล์ แล้วย้ายของข้างในทั้งหมดมาไว้ในโฟลเดอร์ `claude-brain` ตรง ๆ
   ให้ `CLAUDE.md` อยู่ชั้นบนสุด ไม่ใช่ในโฟลเดอร์ย่อย
3. โฟลเดอร์ `.claude` เป็นโฟลเดอร์ซ่อน ต้องย้ายมาด้วย
   (Mac กด `Cmd + Shift + .` ใน Finder เพื่อให้เห็นไฟล์ซ่อน · Windows เปิดเมนู View แล้วเปิด Hidden items)
4. เปิดโฟลเดอร์นั้นในฝั่ง **Code** แล้วทำข้อ 5 และ 6 ด้านบน

## ข้างในมีอะไร

| ที่ | มีอะไร | เราแก้ไหม |
|---|---|---|
| `CLAUDE.md` | กติกาที่ Claude อ่านก่อนทุกครั้ง: ถามก่อน ไม่เริ่มเอง · ชื่อจริงไม่ขึ้นลิงก์ · ตอบจากส่วนจำ ไม่เดา | แก้ได้ เป็นกติกาของเรา |
| `core/` | ทีมเราเป็นใคร ใครทำอะไร น้ำเสียงของเรา | แก้เป็นทีมเราเอง |
| `users/` | คนที่เราทำงานให้ เขาอยากได้อะไร | แก้เป็นลูกค้าหรือผู้ใช้ของเรา |
| `decision-log.md` | เรื่องที่ตัดสินแล้ว และเพราะอะไร ใหม่สุดอยู่บน | เพิ่มเรื่อย ๆ |
| `meetings/` | สรุปประชุมที่ `/meeting-slide` เขียนไว้ | Claude เขียนให้ |
| `slides/` | สไลด์ที่ `/meeting-slide` ทำ (มีหลังใช้ครั้งแรก) | Claude เขียนให้ |
| `templates/slides.html` | Template สไลด์ | แก้สี แก้โลโก้ได้ |
| `sample/` | transcript ประชุม 35 นาที ตัวอย่างสมมติ | ไว้ฝึก |
| `.claude/skills/` | คำสั่งที่เก็บไว้ใช้ซ้ำ ตอนนี้มี `/meeting-slide` | เพิ่มของเราเองได้ |
| `docs/` | คู่มือชุดนี้ | ไม่ต้องแก้ |

ข้อมูลทีมและคนในไฟล์ตั้งต้นเป็น **ตัวอย่างสมมติ** ทั้งหมด

## ทำให้เป็นของเรา

สั่ง Claude ได้เลย ไม่ต้องเปิดไฟล์เอง เช่น

- **ช่วยแก้ core/team.md เป็นทีมของเรา: ทีมมี 4 คน** แล้วเล่าต่อให้ครบว่าใครทำอะไร
- **ประชุมเมื่อกี้ตัดสินว่า [เรื่อง] เพราะ [เหตุผล] ช่วยเพิ่มใน decision-log.md**
- **อ่าน CLAUDE.md แล้วบอกหน่อยว่ากติกาข้อไหนไม่เหมาะกับงานเรา**

Claude อ่าน `CLAUDE.md` เองทุกครั้งที่เริ่ม session ในโฟลเดอร์นี้ แก้แล้วมีผลตั้งแต่ session ถัดไป

## ทำ skill ของเราเอง

skill คือ prompt ที่เก็บไว้ใช้ซ้ำ อยู่ที่ `.claude/skills/<ชื่อ>/SKILL.md` แล้วเรียกด้วย `/<ชื่อ>`

1. ทำงานนั้นกับ Claude จนได้ผลที่ชอบหนึ่งครั้ง
2. พิมพ์ **ช่วยเก็บวิธีที่เราเพิ่งทำเป็น skill ชื่อ weekly-report**
   (ชื่อใช้ภาษาอังกฤษตัวเล็ก คั่นด้วย `-`)
3. อ่านไฟล์ `SKILL.md` ที่ได้ ตรงไหนไม่ใช่ แก้หรือสั่งให้แก้
4. เปิด session ใหม่ แล้วพิมพ์ `/weekly-report`

ใช้ไปสักพัก อ่านต่อ [4 · ใช้ส่วนจำทุกวัน](04-brain-day-to-day.md): จดเพิ่มตอนไหน แก้ยังไง เรียกใช้ให้ถูกงาน
