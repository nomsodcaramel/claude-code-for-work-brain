# 5 · อัดประชุม เป็นสไลด์สรุป (หลังคลาส)

ในคลาสเราใช้ transcript ที่เป็นข้อความ หน้านี้สำหรับประชุมจริงของเรา ที่อัดไว้เป็นวิดีโอหรือเสียง
Claude ฟังไฟล์เสียงหรือวิดีโอเองไม่ได้ skill `/transcribe` จึงถอดเสียงเป็นข้อความบนเครื่องเราก่อน แล้วค่อยส่งต่อให้ `/meeting-slide`

```
ไฟล์อัดประชุม → /transcribe → เราตรวจชื่อ วัน ตัวเลข → /meeting-slide → สไลด์สรุปเป็นลิงก์
```

ฟรี ไม่ต้องสมัครอะไรเพิ่ม ไฟล์เสียงไม่ออกจากเครื่องเรา ส่วนข้อความ transcript ที่ถอดแล้ว Claude อ่านเหมือนข้อความที่เราพิมพ์

## ก่อนเริ่ม ครั้งเดียว

- ที่ว่างในเครื่องอย่างน้อย 3 GB และต่อ Wi-Fi (ครั้งแรกจะดาวน์โหลดตัวถอดเสียงประมาณ 1.6 GB อย่าใช้เน็ตมือถือ)
- คอมบริษัท: ถามฝ่าย IT ก่อน เครื่องบริษัทมักลงโปรแกรมเองไม่ได้
- โปรแกรม **uv** ช่วยรันตัวถอดเสียง ไม่ต้องติดตั้งเอง พิมพ์ **/transcribe** แล้ว Claude จะขอติดตั้งให้ กด Allow

## อัดประชุม

- **ขออนุญาตทุกคนในประชุมก่อนอัด** ทุกครั้ง
- ประชุมออนไลน์: ใช้ปุ่มอัดของโปรแกรมประชุม ได้ไฟล์ `.mp4`
  ไฟล์อัดของ Teams อยู่ใน OneDrive ของ Google Meet อยู่ใน Google Drive ดาวน์โหลดมาไว้ในเครื่องก่อน
- โปรแกรมประชุมถอดข้อความให้แล้ว (Teams Zoom Meet): ดาวน์โหลดไฟล์ข้อความนั้น ใช้กับ **/meeting-slide** ได้เลย ไม่ต้อง /transcribe
- ประชุมในห้อง: อัดเสียงด้วยมือถือ วางไว้กลางโต๊ะ ได้ไฟล์ `.m4a` หรือ `.mp3` แล้วส่งเข้าคอม
- ใช้ได้: `.mp4` `.mov` `.m4a` `.mp3` `.wav` `.webm`

## ทำทีละขั้น

1. ย้ายไฟล์อัดไปไว้ในโฟลเดอร์ `recordings` ในโฟลเดอร์ส่วนจำ (ไม่มีโฟลเดอร์นี้ สร้างใหม่ได้เลย)
2. พิมพ์ **/transcribe** แล้วตอบว่าประชุมวันไหน ใครเข้าบ้าง
3. รอ Claude ถอดเสียง เสียบสายชาร์จไว้ และอย่าพับจอ
4. Claude ถามทีละข้อ เรื่องชื่อคน วัน วันที่ ตัวเลข ที่ได้ยินไม่ชัด ตอบจากที่เราจำได้ จำไม่ได้ก็บอกว่าจำไม่ได้
5. เสร็จแล้วพิมพ์ **/meeting-slide** (หรือกดตัวเลือก "ทำ /meeting-slide เลย") ได้สไลด์สรุปเป็นลิงก์เหมือนในคลาส

## ใช้เวลาเท่าไร

- บน MacBook Air M3 ไฟล์ยาว 7 นาที 44 วินาที ถอดเสร็จใน 2 นาที 26 วินาที (ตอนเปิดโปรแกรมอื่นอยู่ด้วย)
  ประชุม 1 ชั่วโมงจึงใช้ประมาณ 20 นาที เครื่องรุ่นเก่ากว่าอาจนานกว่านี้
- ครั้งแรกบวกเวลาดาวน์โหลดตัวถอดเสียงอีก (ขึ้นกับเน็ต)

## ต้องรู้ก่อนใช้

- **ไม่รู้ว่าใครพูด** transcript มีแค่นาทีกับข้อความ ในสรุป ช่อง "ใครพูด" จะเป็น "ไม่ชัดใน transcript"
- **ชื่อคน วัน วันที่ ตัวเลข ผิดได้** เช่น "เสาร์" ถอดออกมาเป็น "สาว" จึงต้องมีขั้นตรวจทุกครั้ง อย่าข้าม
- **ขั้นตรวจถามแค่ ชื่อ วัน วันที่ ตัวเลข เวลา** คำอื่นยังเพี้ยนได้ เช่น "ส่ง" เป็น "ทรง" "ร่าง" เป็น "ร่วง"
  ในการทดสอบ สไลด์เขียนตามความหมายได้ถูก แต่ถ้าเห็นประโยคแปลกในสไลด์ บอก Claude ให้แก้ตอน "เอ๊ะ หลัง"
- ทดสอบแล้วบน Mac กับเสียงพูดสังเคราะห์ภาษาไทย ยังไม่ได้ทดสอบบน Windows และกับประชุมจริงที่หลายคนพูดพร้อมกัน
  ประชุมจริงมีเสียงรบกวน คนพูดแทรกกัน คำภาษาอังกฤษ ผลจะผิดมากกว่าในการทดสอบ

## ความเป็นส่วนตัว

- ถอดเสียงบนเครื่องเรา ไฟล์อัดไม่ถูกส่งขึ้นเน็ต
- ไฟล์อัดอยู่ในโฟลเดอร์ `recordings` เท่านั้น ห้ามแนบหรือทำลิงก์ (กติกาข้อ 2 ใน `CLAUDE.md`)
- transcript ที่ถอดแล้ว Claude อ่านผ่านบัญชีของเรา ถูกส่งไปประมวลผลที่ Anthropic ประชุมงานบริษัท ถามฝ่าย IT ก่อน
- transcript มีชื่อจริงของคนในประชุม ก่อนทำลิงก์สไลด์ Claude จะตัดชื่อจริงออก ตรวจอีกรอบก่อนกด Share
  รายชื่อจริงยังอยู่ในสรุปใน `meetings/` บนเครื่องเรา
