Claude Code for Work

ติดตั้ง Claude Code
บนคอมของเรา

ทำ 4 ขั้นนี้ให้ครบก่อนวันเรียน ที่เหลือเราทำด้วยกันในคลาส

ต้องมีก่อน Mac (macOS 13 ขึ้นไป) หรือ Windows 10 ขึ้นไป · RAM 4 GB ขึ้นไป บัญชี Claude แพ็กเกจ Pro ขึ้นไป (แพ็กเกจฟรีใช้ Code ไม่ได้) อินเทอร์เน็ต

Setup4 ขั้นรูปเป็นภาพวาด จอจริงอาจต่างนิดหน่อย

  1. 1

    ดาวน์โหลดแอป Claude

    กดลิงก์ claude.com/download

    Macเปิดไฟล์ที่โหลดมา แล้วลาก Claude ไปใส่โฟลเดอร์ Applications Winเปิดไฟล์ติดตั้ง กดไปตามขั้นตอน แล้วลง Git for Windows ด้วย git-scm.com/downloads/win
  2. 2

    เปิดแอป แล้ว Sign in ด้วยบัญชี Claude ของเรา

    Mac เปิดจาก Applications · Windows เปิดจาก Start menu

  3. 3

    ด้านบนของแอป กด Code ฝั่งขวา

    แอปมีสองฝั่ง: ซ้ายคือแชท (รวม Cowork แล้ว) ขวาคือ Code วันนี้เราใช้ Code เพราะทำงานกับไฟล์ในคอมเราได้

  4. 4

    เลือก Local แล้วกด Select folder

    สร้างโฟลเดอร์ว่างไว้หนึ่งอันก่อน เช่น claude-brain แล้วเลือกโฟลเดอร์นั้น

    ในคลาสเราจะ copy ลิงก์นี้ ไปบอก Claude ให้ติดตั้งลงโฟลเดอร์นี้ github.com/nomsodcaramel/claude-code-for-work-brain

ติดตรงไหน

กด Code แล้วขึ้นให้อัปเกรดบัญชียังไม่ใช่ Pro ต้องสมัครแพ็กเกจ Pro ขึ้นไปก่อน
เบราว์เซอร์เด้งหน้า Sign inSign in ในเบราว์เซอร์ให้เสร็จ จากนั้นปิดแอปแล้วเปิดใหม่
บน Windows Claude บอกว่าทำคำสั่งไม่ได้ลง Git for Windows แล้วปิดแอปแล้วเปิดใหม่
