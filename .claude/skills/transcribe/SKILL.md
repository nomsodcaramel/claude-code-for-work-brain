# transcribe

ไฟล์อัดประชุม → transcript `[mm:ss]` → ผู้ใช้ตรวจชื่อ วัน วันที่ ตัวเลข → พร้อมใช้กับ `/meeting-slide`

Claude ฟังเสียงเองไม่ได้ skill นี้ใช้ตัวถอดเสียงบนเครื่องนี้ (faster-whisper) ไฟล์ไม่ออกจากเครื่อง
ตัวถอดเสียงได้ยินชื่อคน วัน และวันที่ผิดบ่อย (ในการทดสอบ "เสาร์" กลายเป็น "สาว" ทุกครั้ง และวันที่เดียวกันที่พูดหลายครั้ง ถอดออกมาไม่ตรงกัน)
และไม่รู้ว่าใครพูด จึงต้องมีขั้นตรวจทุกครั้ง

## 0 ครั้งแรกครั้งเดียว

- ลอง `uv --version` ไม่เจอ: บอกผู้ใช้ว่า "ต้องติดตั้ง uv โปรแกรมเล็ก ๆ ที่ช่วยรันตัวถอดเสียง ครั้งเดียว" แล้วขอรันคำสั่งทางการ
  - Mac: `curl -LsSf https://astral.sh/uv/install.sh | sh`
  - Windows: `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
  - ติดตั้งแล้วยังเรียก `uv` ไม่เจอ ใช้ `~/.local/bin/uv` แทน
- ครั้งแรกที่ถอด จะดาวน์โหลดโมเดลประมาณ 1.6 GB (ครั้งเดียว) ต้องมีที่ว่างในเครื่องอย่างน้อย 3 GB และต่อเน็ตอยู่

## 1 ไฟล์ไหน

1. ผู้ใช้ให้ path มา ใช้ไฟล์นั้น ไม่ได้ให้ ดูในโฟลเดอร์ `recordings/`
   - ไม่มีไฟล์: บอกว่า "ย้ายไฟล์อัดประชุมไปไว้ในโฟลเดอร์ recordings แล้วพิมพ์ /transcribe อีกครั้ง" แล้วหยุด
   - มีหลายไฟล์: ถามว่าไฟล์ไหน ด้วยเครื่องมือถามคำถาม
2. ถามทีละข้อ ด้วยเครื่องมือถามคำถาม (พิมพ์เองได้เสมอ):
   - **ประชุมวันไหน** · ตัวเลือก: วันที่ของไฟล์ (ดูจากวันที่แก้ไขไฟล์) · วันนี้
   - **ใครเข้าประชุมบ้าง** (เลือกได้หลายข้อ) · ตัวเลือกจากชื่อใน `core/team.md` ไม่เกิน 4 ชื่อ · พิมพ์เพิ่มได้
3. ชื่อไฟล์ที่จะเขียน: `transcripts/<วันที่ประชุม YYYY-MM-DD>-<ชื่อไฟล์อัด ไม่มีนามสกุล>.md`

## 2 ถอดเสียง

- รันจากโฟลเดอร์ส่วนจำนี้ (ที่มี `CLAUDE.md`):
  `uv run .claude/skills/transcribe/scripts/transcribe.py "<ไฟล์อัด>" "transcripts/<ชื่อไฟล์>.md"`
- ใช้เวลานาน (บน Mac ที่ทดสอบ ประมาณหนึ่งในสามของความยาวไฟล์ ประชุม 1 ชั่วโมงประมาณ 20 นาที) รันแบบ background
  แล้วบอกผู้ใช้ว่าจะเสร็จประมาณกี่นาที ให้เสียบสายชาร์จ และอย่าพับจอ
- สคริปต์เขียนทีละบรรทัดระหว่างถอด ถ้าหยุดกลางทาง บรรทัดที่ได้แล้วยังอยู่ในไฟล์
- จบแล้วสคริปต์พิมพ์ "ต้องตรวจ N บรรทัด" พร้อมรายการ ใช้รายการนั้นในข้อ 3

## 3 ตรวจ (ผู้ใช้ตรวจ Claude ห้ามแก้เอง)

1. อ่าน transcript ทั้งไฟล์ หาคำที่เสียงคล้ายชื่อใน `core/team.md` แต่สะกดผิด
   (ที่พบบ่อย: ตัวควบกล้ำหาย เช่น "ปร" เหลือ "ร" · วรรณยุกต์หรือตัวสะกดเปลี่ยน เช่น "ต" เป็น "ด" หรือ "ท")
   รวมกับรายการ "ต้องตรวจ" จากสคริปต์ (หลังลูกศร ← สคริปต์บอกคำที่เจอในบรรทัดนั้น)
   ทุกคำหลังลูกศร ต้องอยู่ในคำถามสักข้อ ห้ามข้ามคำไหน
2. จัดเป็นคำถาม **หนึ่งเรื่องต่อหนึ่งคำถาม** ถามทีละข้อด้วยเครื่องมือถามคำถาม เรียงแบบนี้:
   วันที่และกำหนดส่ง → วันในสัปดาห์ → ชื่อคน → จำนวนเงินและตัวเลข → เวลา
   - แต่ละคำถามแสดงทุกบรรทัดที่พูดถึงเรื่องนั้น พร้อมนาที เช่น
     "วันส่งงาน ในไฟล์ได้ยิน 3 ครั้ง: [12:05] 5 มีนา · [12:40] 15 มีนา · [30:12] 5 มีนา วันจริงคือวันไหน"
   - ตัวเลือก = แบบที่ได้ยินในไฟล์ และคำที่ตรงกับชื่อใน `core/team.md` หรือชื่อวันจริง · พิมพ์เองได้ · ห้ามมีตัวเลือก "แนะนำ"
   - ตัวเลขที่ไม่กำกวม รวมเป็นคำถามเดียว: "ตัวเลขพวกนี้ถูกไหม" ตัวเลือก: ถูกทั้งหมด · มีผิด (พิมพ์บอก)
   - ผู้ใช้จำไม่ได้ เขียนคำนั้นเป็น `[ไม่ชัด: <คำที่ได้ยิน>]` ห้ามเดาแทน
3. แก้เฉพาะคำที่ผู้ใช้ตอบ ห้ามแก้คำอื่น ห้ามเรียบเรียงใหม่ ห้ามลบนาที
4. ใส่หัวไฟล์: `วันที่ประชุม:` และ `คนเข้า:` ตามข้อ 1 แล้วเปลี่ยนบรรทัดที่ขึ้นต้นว่า `ยังไม่ได้ตรวจ:` เป็น
   `ตรวจแล้ว <วันนี้>: ชื่อ วัน วันที่ ตัวเลข ตามที่ผู้ใช้ตอบ <จำนวน> ข้อ`
5. รัน `uv run .claude/skills/transcribe/scripts/transcribe.py check "transcripts/<ชื่อไฟล์>.md"` อีกครั้ง
   บรรทัดไหนยังมีคำที่ไม่ได้ถาม ถามต่อ

## 4 บอกผู้ใช้ แล้วไปต่อ

- บอกสั้น ๆ: เขียนไฟล์ไหน กี่บรรทัด แก้ไปกี่คำ ใช้เวลาถอดเท่าไร
- บอกตรง ๆ ว่า transcript ถอดด้วยเครื่อง ตรวจแล้วเฉพาะคำที่ถาม และไม่มีชื่อคนพูด
- ถามว่าจะทำสไลด์สรุปเลยไหม · ตัวเลือก: ทำ /meeting-slide เลย · ไว้ก่อน

## กติกา

- ไฟล์อัดอยู่ใน `recordings/` บนเครื่องนี้เท่านั้น ห้ามอัปโหลด ห้ามแนบ ห้ามทำลิงก์ (กติกาข้อ 2 ใน `CLAUDE.md`)
- transcript มีชื่อจริง ก่อนทำลิงก์ใด ๆ ตัดชื่อจริงออกตามกติกาข้อ 2
- ทดสอบแล้วบน Mac (Apple M3) กับเสียงพูดสังเคราะห์ภาษาไทยหนึ่งเสียง ยังไม่ได้ทดสอบบน Windows และกับประชุมจริงหลายเสียง
  ถ้าผลแย่ บอกผู้ใช้ตรง ๆ
